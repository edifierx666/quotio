# 截图清单

按下表文件名把截图放进本目录，README 已按这些名字引用。统一用 PNG、浅色主题、窗口宽度约 1200px（Retina 下导出 2x 即可）。

| 文件名 | 画面 | 截取要点 |
| --- | --- | --- |
| `01-services-list.png` | 服务列表（首屏预览） | 3–4 个服务：至少 1 个「运行中」带端口与 PID 标签、1 个「随 magpie 启动 · 队列」、1 个「已停止」 |
| `02-service-editor.png` | 新建 / 编辑服务弹窗 | 填好名称、命令、工作目录、环境变量，鼠标悬停在「启动队列」旁的提示图标上 |
| `03-logs.png` | 日志 | 一个运行中服务的实时输出，含插件以 `▸` 开头的操作记录 |
| `04-update-available.png` | 发现新版本 | 行内显示「v… 可用」，展开「立即更新 / 查看发布页 / 忽略此版本」 |
| `07-tunnel-share.png` | 分享到公网弹窗 | 从服务 ⋯ 菜单打开，端口已带入，可见公网警告 |
| `08-tunnels-list.png` | 隧道标签页 | 1 条「已连通」的隧道，显示 trycloudflare 地址与复制 / 打开 / 关闭按钮 |

截图前注意遮盖：真实令牌、内网地址、用户名路径（如 `/Users/<你的用户名>`）。
